Research

★ LEAD Primary (Anthropic post) + TLDR AI and Let's Data Science coverage. Vendor's own evals.

Anthropic: 'dreaming' lifts a wiki-based memory score from 13% to 48% over 128 sessions, and still trails search alone (53%)

Anthropic Engineering (Lance Martin, Nov 6) defines a four-layer agent memory stack (transcripts, notes, wiki-style representations, injected context) and an offline 'dreaming' pass that re-reads transcripts to fix notes and rebuild pages. Reported: CL-Bench mean reward 0.383 to 0.700 (Opus 4.7); wiki plus search 61% versus 53% for search alone; a per-task dreaming setup kept 57 of 57 contract facts versus 41 of 57 for a shared table.

Why it matters: Memory is maintenance, not storage: build the audit-against-transcript pass before the wiki.

Primary (OpenRouter, vendor claims) + TLDR AI.

OpenRouter's new Auto Router and Auto Code: model chosen per request from eleven factors plus live price and provider health

Announced Nov 6. A fast decision model rates each request, then routing weighs cost, health and cache status. The post claims up to 4x over the old router (methodology not given) and that Auto Code matches Opus 5.5 on five benchmarks at 74% lower cost. It stays on one model for nearly nine in ten agent turns to protect the input cache, and admits no router beats the best single model everywhere.

Why it matters: Routing is now a harness decision; the cache-stickiness trade-off is the part to copy or test.
