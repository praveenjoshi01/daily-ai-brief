Outdated API references fell from 7% to 1.3%. The model didn't change. The agent's context did.

That's the headline from Stripe's integration evals, published November 19. Coding agents (Claude Code, Codex, OpenCode) built Stripe integrations across 69 scenarios, with and without Stripe's agent plugin.

Why it matters if you build with agents:
- Every one of 14 model-and-harness pairs scored higher with the plugin, by roughly 3 to 8 points.
- Web searches per eval dropped 96%. The agent stopped guessing and started checking.
- Under strict grading, where every required criterion has to pass, the post reports an average of 29.4%, not the headline figure. Report the strict number.

Caveat: Stripe wrote the eval and owns the product. Nobody has independently re-run it yet.

Question for builders: when you add tooling to an agent, do you measure stale references, or only whether the code runs?
