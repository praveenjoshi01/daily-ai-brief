## Engineering & Tooling
1. **★ LEAD — Sentry's Junior: steering an agent with an egress proxy that denies and reacts** — [David Cramer, “A Little Determinism” (Oct 29)](https://cra.mr/a-little-determinism) · [Junior README (Sentry)](https://github.com/getsentry/junior) · [Vercel Sandbox credential-injection changelog (via search result; page not opened)](https://vercel.com/changelog/safely-inject-credentials-in-http-headers-with-vercel-sandbox). Every outbound request from the agent's sandbox passes through a man-in-the-middle proxy. The proxy injects credentials, rejects raw shell calls (e.g. a direct PR-creation mutation) with a 403 that tells the agent which tool to use instead, and turns CI/review events into injected user messages (“watches”). Post reports no benchmarks; evidence is qualitative. Junior's repo is tagged non-production, and its docs confirm only the PR-babysitting behaviour, not the proxy internals. *Why it matters:* Enforcement at the network boundary is a harness pattern you can copy without touching the model or prompts.
2. **Making agents fast: inference is often not the bottleneck** — [Martin Alderson (Oct 29)](https://martinalderson.com/posts/making-agents-fast/). Single-author practitioner post. Argues thinking budgets, tool-call overhead, sandbox suspend/resume and polling loops can dominate task time. Illustrative example: in a 60-second task, a 2x faster inference tier yields only a 1.25x overall speedup. Author says figures are rough, not benchmarks. *Why it matters:* Profile the whole loop before paying for a faster model tier.
3. **Vercel AI Gateway “virtual models”** — [Vercel blog (Oct 28)](https://vercel.com/blog/ai-gateway-virtual-models). An app points at an ID such as vmc/coding-agent; the underlying model, fallbacks and zero-data-retention settings can change without a redeploy, reaching apps within minutes. Vercel says 125 new models from 10+ labs arrived on the gateway in 90 days. Vendor announcement; provider-specific options must be re-checked after a swap. *Why it matters:* Model choice becomes configuration, so evals on a candidate ID become the safety net.
4. **Roblox: org-specific rules lift AI code-review acceptance to ~70%** — [DX / Engineering Enablement newsletter (Oct 30)](https://newsletter.getdx.com/p/robloxs-approach-to-tripling-ai-code). SINGLE SECONDARY SOURCE (newsletter episode summary of a podcast; carried over from yesterday). Reported: AI review comments accepted ~70% vs 50–55% for human comments, ~5% of PRs auto-merge, 90% lower cost per rule evaluation via caching. *Why it matters:* Mining past review comments into rules is a copyable pattern; numbers are unverified.
5. **Meta's just-in-time testing at scale** — [TLDR AI, Oct 30 (summary only)](https://engineering.fb.com/2026/10/29/security/catching-bugs-before-they-land-jittestings-human-on-the-loop-approach-at-full-scale/). 9. **DeepMind Institute essay: “The Economics of Intelligence”** — [DeepMind Institute (Oct 29)](https://institute.deepmind.com/essays/the-economics-of-intelligence/). Imas, Koh and Legg argue competence and coordination are separate thresholds, and that AI is advancing faster on competence. A small quiz study (100 people) found complementary pairs beat random pairs by 32%. Conceptual essay; the formal model is in a separate paper not reviewed. Not Google's official view. *Why it matters:* Frames why multi-agent coordination, not single-agent skill, may gate impact.
