## Lead

1. **★ LEAD — GitHub “Rubicon”: 5,000 concurrent agents, 7,200 pushes/s to one repo in internal tests — by deciding which writes need agreement** — GitHub's Nov 5 engineering post splits a Git write in two: objects (packs) go to Azure Blob Storage with no coordination, and only the small reference update is ordered through a replicated compare-and-swap log (Ref-CAS). Serving replicas become disposable caches, and background nodes compact packs. GitHub reports 5,000 agents pushing 7,200 times per second to one repository in internal tests; it is in limited private preview with broader rollout planned for early next year. The Register (Oct 9) separately reported a 35x internal write improvement for the rebuild and noted it came from internal tests with no timeline. Sources: [GitHub Blog (primary)](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/) · [GitHub Blog, Oct 21 (primary, background)](https://github.blog/engineering/architecture-optimization/the-bridge-to-agent-scale-git-infrastructure/) · [The Register (independent)](https://www.theregister.com/a/5302148) · [TLDR Dev](https://tldr.tech/dev). *[Primary + independent secondary + GitHub's earlier posts]* *Why it matters: Agent-scale write load is now a storage-architecture problem. If your agents share a repo, expect per-branch ordering to matter more than raw push volume.*

2. **Thinking Machines Inkling 2 Small: 594B-parameter MoE (17B active), closed weights now, Apache 2.0 weights promised next week** — The Nov 5 post describes an image-capable mixture-of-experts model with variable effort, trained natively in NVFP4, available through Tinker. It reports 72.1% on DeepSWE v1.1 and 86.3% on SWEBench Pro v2 (Hard), all self-reported. Full weights are promised under Apache 2.0 after external safety testing; that date is an announced plan, not a confirmed release. The post itself lists weaknesses: less succinct output and suboptimal tool choice in codebases with many skills. Sources: [Thinking Machines (primary)](https://thinkingmachines.ai/news/inkling-2-small/) · [TLDR AI](https://tldr.tech/ai) · [TLDR Dev](https://tldr.tech/dev). *[Primary + newsletter (2 editions)]* *Why it matters: A possible open-weight agentic coder, but wait for the weights and independent evals before changing a stack.*
