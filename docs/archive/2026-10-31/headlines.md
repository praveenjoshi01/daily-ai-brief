## Engineering & Tooling
1. **★ LEAD — Meta's Catching JiTTests: LLM-generated bug-catching tests, filtered to cut review load ~70%** — [Engineering at Meta](https://engineering.fb.com/2026/10/29/security/catching-bugs-before-they-land-jittestings-human-on-the-loop-approach-at-full-scale/) · [arXiv 2601.22832](https://arxiv.org/abs/2601.22832) · [InfoQ (re-reports Meta)](https://infoq.com/news/2026/04/meta-jit-testing-ai-detection). Tests are generated from risky diffs overnight; an LLM-judge ensemble plus a deterministic rule assessor decide which failures reach an engineer. Paper: 22,126 tests analysed; 41 catches reported, 8 true positives, 4 serious. Blog: 60% engineer-reported true-positive rate. *Why it matters:* The value is in the filter stack and targeting around the generator, not the generator.
2. **Factory's Droid 1.0: a model-independent agent harness** — [Factory](https://factory.com/news/frontier-harness). Vendor-reported Terminal-Bench 4 results: 65.2% on Claude Opus 5.5 vs 57.6% for Claude Code, and up to 24% lower cost per passed task. Uses programmatic tool calling (agent-written scripts running many tool calls per request) and loads 2 tool definitions up front instead of 11. Narrow benchmark; some comparisons use modeled figures. *Why it matters:* Harness design (tool loading, cache discipline, loop limits) is now a measurable lever.

## Research
6. **Epoch AI: an open-weight model turns published Firefox patches into working exploits** — [Epoch AI](https://epoch.ai/publications/open-weight-models-patch-gap). GLM 5.3 compromised 6 of 6 tested Firefox releases (file-read, not code execution) in an offline setup, ~$1,000 per version at API pricing, fastest run ~12 hours. No Chrome equivalent found; one model, limited software tested. *Why it matters:* Patch-gap windows shrink when exploit work is cheap; update cadence is a security control.
7. **Raindrop: leadership dynamics in 8-agent swarms** — [Raindrop](https://www.raindrop.ai/blog/agent-swarm-leadership/). 2,160 simulated incident-response teams; plans were common (86%) but only ~5% produced a leader. First-listed agent was ~3x likelier to issue a plan, and reversing the list reversed it. Simulated environment; small classifier sample. *Why it matters:* Prompt ordering can silently decide who coordinates your multi-agent system.
