LEAD STORY

Meta's Catching JiTTests: LLM-generated bug-catching tests, filtered to cut review load ~70%

— Engineering at Meta · arXiv 2601.22832 · InfoQ (re-reports Meta). Tests are generated from risky diffs overnight; an LLM-judge ensemble plus a deterministic rule assessor decide which failures reach an engineer. Paper: 22,126 tests analysed; 41 catches reported, 8 true positives, 4 serious. Blog: 60% engineer-reported true-positive rate. Why it matters: The value is in the filter stack and targeting around the generator, not the generator.

Factory's Droid 1.0: a model-independent agent harness

— Factory. Vendor-reported Terminal-Bench 4 results: 65.2% on Claude Opus 5.5 vs 57.6% for Claude Code, and up to 24% lower cost per passed task. Uses programmatic tool calling (agent-written scripts running many tool calls per request) and loads 2 tool definitions up front instead of 11. Narrow benchmark; some comparisons use modeled figures. Why it matters: Harness design (tool loading, cache discipline, loop limits) is now a measurable lever.

Roblox: org-specific rules lift AI code review acceptance to ~70%

— DX newsletter / Engineering Enablement episode. Single secondary source (newsletter episode summary; not independently verified). Reported: AI review comments accepted ~70% vs 50–55% for human comments, ~5% of PRs auto-merge, 90% lower cost per rule evaluation via caching. Why it matters: Mining past review feedback into rules is a copyable pattern; treat numbers as unverified.

Frontier Labs & Open Models

Mistral releases Mistral Large 4 open weights

— Mistral. 1T-parameter MoE (repo name implies ~52B active), modified-MIT license with a commercial carve-out for model-as-a-service. Mistral-reported: 41% Terminal-Bench 4.0, 51% on the Artificial Analysis Cyber Index, $0.70/$2.10 per million input/output tokens. Hardware requirements not stated. Why it matters: A large open-weight option for self-hosted agentic coding; benchmarks are vendor-reported.

Research

Epoch AI: an open-weight model turns published Firefox patches into working exploits

— Epoch AI. GLM 5.3 compromised 6 of 6 tested Firefox releases (file-read, not code execution) in an offline setup, ~$1,000 per version at API pricing, fastest run ~12 hours. No Chrome equivalent found; one model, limited software tested. Why it matters: Patch-gap windows shrink when exploit work is cheap; update cadence is a security control.

Raindrop: leadership dynamics in 8-agent swarms

— Raindrop. 2,160 simulated incident-response teams; plans were common (86%) but only ~5% produced a leader. First-listed agent was ~3x likelier to issue a plan, and reversing the list reversed it. Simulated environment; small classifier sample. Why it matters: Prompt ordering can silently decide who coordinates your multi-agent system.
