## Research

3. **NVIDIA AutoCompress: hardware-guided pruning takes Nemotron 3.5 Super from 120B to 74B and keeps 95% of its mean score** — The arXiv paper builds serving-engine cost models for latency, throughput and memory into differentiable architecture search. It reports gains over the Minitron pruning baseline of 6.57 points on RTX 5070, 2.35 on RTX 5080 and 0.57 on H100 across eight benchmarks. I read the abstract and listing only, not the full paper. Sources: [arXiv:2611.08290 AutoCompress](https://arxiv.org/abs/2611.08290) · [TLDR AI, Nov 10 (inbox)](https://tldr.tech/ai) *[Primary (arXiv abstract, fetched) + TLDR AI. Abstract-level read only.]* *Why it matters: Compress for the hardware you serve on, not for parameter count.*


## Engineering & Tooling

4. **★ LEAD — 1,000 Fable 5.2 agents reproduced a formal Fermat's Last Theorem proof in 28.7 hours, coordinating only through Git and Postgres** — Anthropic's team ran one lead and 999 helpers, each in its own VM with no network except a gateway pipe, plus per-agent Git branches and a shared Postgres database for claims, notes and logs. The September effort needed 11 days; this run used about one-third the output tokens and produced a proof one-seventh the length. The authors call it a toy experiment, and cost was not reported. Sources: [Anthropic: Safely scaling multi-agent teams with Claude Fable 5.2](https://claude.dev/blog/safely-scaling-multi-agent-teams-with-fable-5-2/) · [TLDR Dev, Nov 10 (inbox)](https://tldr.tech/dev) · [TechRadar (Sept baseline)](https://techradar.com/pro/anthropic-formalizes-fermats-last-theorem-like-never-before-using-claude-but-it-still-took-11-days-to-write-out) *[Primary (Anthropic post, fetched) + TLDR Dev; September baseline corroborated by TechRadar. Vendor's own experiment.]* *Why it matters: Coordination, isolation and monitoring, not the model alone, are what let agent count scale; copy the claim-a-subtask table and the fail-closed command monitor.*

5. **Osmani's model-selection guide: raise effort before changing model; low-then-retry hit about 97% at $0.17 per task** — The guide recommends starting on Opus 5.5 at medium effort and escalating through self-verification, one effort level, then a bigger model. In its SWE-bench-style example, Opus 5.5 at low with failures retried at high passed about 97% of tasks at roughly $0.17 each, against 95.3% at $0.29 for high on everything. It also warns that prompt caches belong to one model, and Fable 5.2 thinking blocks must stay append-only or the API returns a 400. Sources: [Addy Osmani: Which Claude model should you build with?](https://claude.dev/blog/which-claude-model-should-you-build-with/) · [TLDR Dev, Nov 10 (inbox)](https://tldr.tech/dev) *[Primary (guide, fetched) + TLDR Dev. Author's numbers, not independently reproduced.]* *Why it matters: A concrete escalation order and cache and thinking-block gotchas you can encode in your router today.*

6. **PostHog: decision models skip 98.7% of LLM calls in a PII gate** — PostHog uses small models that return a typed answer and a calibrated probability before calling a large model. Two narrow yes/no checks gate its session-summary rewrite, with a low 0.4 threshold because a missed leak costs more than an extra call. Authors note thresholds do not transfer across tasks or model versions, and vendor cost claims are not independently measured. Sources: [PostHog: Not everything needs an LLM](https://newsletter.posthog.com/p/decision-models) · [TLDR Dev, Nov 10 (inbox)](https://tldr.tech/dev) *[Primary (PostHog newsletter, fetched) + TLDR Dev. Vendor-supplied cost claims noted.]* *Why it matters: Gate expensive calls with calibrated narrow classifiers, and set thresholds by the cost of each error type.*

7. **OpenAI at AI Engineer Code Summit: Codex cloud and local tasks are merging; voice as a control plane** — A Latent Space attendee report says OpenAI engineers described publishing a cloud environment once and running tasks in isolated instances, handing local work to the cloud, voice used to manage threads, and 'dots' personal agents the speaker called awkward at first.
