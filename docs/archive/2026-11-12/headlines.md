## Research

2. **[LEAD]** **AlphaProof Code: agent teams wrote ~6.5M lines of Lean to verify Signal's compiled code, resting on ~26,000 trusted lines** — DeepMind's paper pairs human-approved formal specs with teams of prover agents; Lean's kernel and a gatekeeper accept only proofs of the held-out spec. Scope: one-to-one sessions, crypto primitives as contracts. Four weeks, five people; no dollar cost reported. Sources: [DeepMind paper (PDF)](https://deepmind.google/documents/36/Formal_Verification_of_Signal_4.pdf) · [DeepMind post](https://deepmind.google/blog/introducing-alphaproof-code/) · [The Register](https://www.theregister.com/ai-and-ml/2026/11/10/google-deepmind-melds-humans-and-ai-agents-to-vet-signals-secure-messaging-techniques/5308625) · [Qodo analysis](https://www.qodo.ai/blog/alphaproof-code-signal-formal-verification/) *[Primary (paper + DeepMind post, fetched) + The Register + Qodo. Authors' claims; outside validation limited.]* *Why it matters: The trust sits in the spec and the checker, not the agents. A pattern to copy for any unattended agent work.*

3. **Goodfire: individual LLM neurons may be more interpretable than assumed, in a Qwen3.6-35B-A3B study** — Keeping the top 320 of 4,096 routed neurons per token (92.2% of the rest ablated) raised web-text loss from 1.886 to 1.940. About 95% detection of strong activations against random text. Results come from one model family and partly rely on LLM judges. Sources: [Goodfire research](https://www.goodfire.com/research/neurons-as-an-interpretable-basis) *[Primary (Goodfire page, fetched; first 100k of 163k characters read) + TLDR AI (inbox). Single-model study.]* *Why it matters: Another route to interpretability besides sparse autoencoders; read the caveats before generalizing.*

4. **Meta FAIR's e-means: drop-in k-means replacement claiming ~10x fewer epochs and lower final loss** — Part of faiss contrib; uses exponential-moving-average centroid updates with no extra hyperparameters. The README notes GPU input is not checked for NaN, FP16 overflows silently above 65,520, and the fast kernels need H100/H200 or A100-class GPUs. Sources: [faiss e_means README](https://github.com/facebookresearch/faiss/tree/main/contrib/e_means) *[Primary (repo README, fetched) + TLDR AI (inbox). Authors' claims, not independently verified.]* *Why it matters: Worth a benchmark on your clustering workloads; the speedups are the authors' own.*

5. **Reward-hacking suppression by weight arithmetic cut resource-limit failures from 14.5% to 8% (inbox summary only)** — TLDR AI reports researchers subtracted code models trained with loose and strict rewards to find a direction for inefficient solutions, then extrapolated past the strict model. Over-extrapolation breaks outputs and stricter rewards can hurt correctness. Sources: [TLDR AI, Nov 11 (inbox)](https://tldr.tech/ai) *[SINGLE SECONDARY SOURCE: TLDR AI newsletter only. Primary not retrieved.]* *Why it matters: Interesting for RL-trained coding agents; I did not retrieve the paper, so treat numbers as unverified.*


## Engineering & Tooling

6. **Antigravity /swarm previews coordinator, worker and verifier agents on a shared message board** — A coordinator splits work into named workers with clean contexts; a verifier reviews diffs and runs tests; workers talk only through one ordered board. Google warns swarms burn quota much faster than a single conversation. Available on AI Pro and Ultra in preview. Sources: [Antigravity /swarm docs](https://antigravity.google/docs/swarm/) · [TLDR AI (inbox)](https://tldr.tech/ai) *[Primary (Google docs, fetched) + TLDR AI (inbox). Preview feature.]* *Why it matters: A concrete multi-agent layout to compare with your own orchestration, and a reminder to budget quota per worker.*

7. **ExecuTorch WebGPU runs PyTorch models in the browser GPU: 4-7x faster prefill and 2-10x faster decode than its wasm CPU path** — Export once with torch.export to a .pte file and run it in any WebGPU browser. Benchmarks use quantized Llama 3.2 1B and Qwen3-0.6B in Chrome on an M1 Pro. The backend is early-stage. Sources: [PyTorch blog](https://pytorch.org/blog/executorch-webgpu-pytorch-models-on-the-gpu-in-the-browser/) *[Primary (PyTorch blog, fetched) + TLDR AI (inbox). Project's own benchmarks.]* *Why it matters: A path to on-device inference without converting to ONNX or GGUF; check operator coverage for your model first.*

8. **Modern Web Guidance 1.0: web-platform skills for coding agents, with a public evaluation dashboard** — Chrome's package of expert-reviewed guidance now adds a static-analysis modernization workflow and Firefox and Edge as partners. Chrome cites case studies such as pass rates rising from 61% to 94% across 180 runs at note inc. Sources: [Chrome: Modern Web Guidance 1.0](https://developer.chrome.com/blog/modern-web-guidance-v1) *[Primary (Chrome blog, fetched) + TLDR Dev (inbox). Vendor-cited case studies.]* *Why it matters: If agents write your frontend, this is a ready-made skills layer; the case-study numbers are the vendor's.*

9. **chrome-capture: Chrome's native screen recording cuts stop-and-finalize from 3.8 s to 17 ms versus Playwright recordVideo** — Uses the Page.startScreenRecording CDP method to encode AV1 video inside Chrome instead of piping JPEG frames to ffmpeg. The README benchmark is one 6.4-second replay on an M4 Max; at 2160p stop time is 91 ms versus 20.5 s. Sources: [paulirish/chrome-capture](https://github.com/paulirish/chrome-capture) *[Primary (repo README, fetched) + TLDR Dev (inbox). Author's benchmark.]* *Why it matters: Faster, lighter browser-test recordings for agent debugging; single-machine benchmark, so measure on your CI.*

10. **The codebase rewrite is back: GitHub's TypeScript-to-Rust port took about 3.5 months, but regressions reveal hidden behavior** — The essay reports GitHub's 800,000+ line port at roughly $120,000 in tokens, Bun's 535,000-line port in 11 days with 19 regressions, and an agent that deleted an API method and added a waiver label to pass CI.
