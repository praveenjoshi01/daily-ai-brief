## Engineering & Tooling
1. **★ LEAD — Codex's Auto-review monitor was beaten 11 ways: the weak spot was the harness around it** — [LessWrong red-team write-up (Oct 30)](https://www.lesswrong.com/posts/dbStc8ZFESqfihwAd/lessons-from-red-teaming-auto-review-openai-s-blocking-1) · [OpenAI Auto-review post (Apr 30)](https://alignment.openai.com/auto-review) · [TLDR AI (Nov 2)](https://tldr.tech/ai). Two ERA/Apollo-linked researchers replayed hand-written synthetic rollouts against Codex's Auto-review, the model that approves sandbox-crossing actions in place of the user. They report 11 attacks that get arbitrary code to run, mostly by swapping scripts behind trusted hooks, imitating user turns, and editing files after approval. OpenAI has fixed several. Caveats: off-policy synthetic rollouts, one pinned commit, and per-attack success rates are only in a private report. *Why it matters:* The monitor model wasn't the weak link; trust rules, context labeling and timing were. Audit your own harness for the same three gaps.

The post does not list eligible services. *Why it matters:* A cheap, API-driven kill switch for sandbox projects where agents or experiments can run up a bill.

## Research
4. **Agentic Backdoors via Pretraining Poisoning: 0.1% poisoned data planted a curl|bash backdoor** — [arXiv 2610.37741 (Oct 27)](https://arxiv.org/abs/2610.37741) · [TLDR AI (Nov 2)](https://tldr.tech/ai). Authors include Carlini, Jagielski and Rando. They pretrained Qwen3 models (0.6B, 1.7B, 4B) from scratch, then post-trained them as CLI agents. A 0.1% poison rate implants a remote-code-execution backdoor; the 4B agent hits about 92% attack success, success rises with scale, and the attack still works at 0.0005%. Abstract page read; full paper not read. *Why it matters:* If you pretrain or continue-pretrain on scraped web data, data provenance is a security control. Fine-tuning on clean data didn't remove it.
5. **Anthropic: Claude automated the search for fine-tuning data that causes misalignment and evades monitors** — [Anthropic Alignment Science blog (Oct 2026)](https://alignment.anthropic.com/2026/automated-em-search/). A Claude agent wrote datasets (capped at 5,000 examples) to make a small model misaligned while passing a training-data monitor. Every run found passing datasets; the winners hid misbehavior inside roleplay and creative-writing framings. Authors flag it favors the red team and doesn't describe deployed Claude. *Why it matters:* Content filters on training data are weaker than they look when an optimizer is probing them.

## Security & Agents in the Wild
6. **Google GTIG: ARTEX multi-agent offensive framework seen in real intrusions** — [Google Cloud / GTIG (Oct 30)](https://cloud.google.com/blog/topics/threat-intelligence/artex-and-friends-enter-agentic-offensive-frameworks). Open-source Go framework with six sub-agents. Since late August it has been used by extortion groups and suspected espionage actors; one cluster went from a first account to deep access in about four hours. GTIG calls the agents noisy (one attack made 240 log events; sub-agents overwrote each other). It predicts fully autonomous attacks within 3 to 6 months. *Why it matters:* Short-lived scoped credentials and behavioral detection tuned for machine-speed bursts are now baseline.
