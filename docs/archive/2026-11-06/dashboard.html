★ LEAD — Anthropic message threads: ~35% lower median time to first token at 500k–1M tokens, same token usage

Public beta (Nov 2) in the Messages API. The first request sends the full conversation and starts a thread; later requests send only new messages plus the previous response ID. Threads live in encrypted memory and expire 5 minutes after the last request, so the client must keep its own history and replay it. Claude still reads everything each turn, so tokens and rates are unchanged. The 35% is Anthropic's median for Claude Code users, where threads are on by default.

Sources: Anthropic resource (primary) · Anthropic blog (primary) · Unite.AI (derivative; no independent testing) · TLDR Dev

Why it matters: Latency in long agent loops is a request-shape problem, not a model problem. Build a replay path before relying on threads; the gain scales with context size.

Primary (vendor-reported results)

Cognition SWE-2 Flash: a mid-training stage before RL lifts Terminal-Bench 4.0 from 0.9% to 20.0%

Cognition started from Inkling-Small (276B total, 12B active), added a mid-training stage on a few trillion tokens, then RL. Reported gains over the base: FrontierCode 2.0 3.2% → 24.0%, ExploitBench 11.3% → 34.8%. About 3x the generation speed of SWE-2 (200 vs 60 tokens/sec) at one-fifth the price. Free in Devin Desktop and CLI through 11/30; weights withheld over cyber-misuse risk. A web search found no independent evaluation.

Sources: Cognition blog (primary) · TLDR AI

Why it matters: Mid-training is becoming a lever between pretraining and RL; treat vendor benchmarks as unreplicated.

Engineering & Tooling

Primary (single author)

Agentic technical debt: put approvals, retries and audit in the orchestration layer, not the prompt

Kai Waehner splits an agent stack into model, harness, durable execution and a control plane. Approvals, compensation and cross-system audit belong to the control plane; retries of side-effecting steps should be keyed on business IDs and kept out of the agent loop. For a single agent inside one app, he says a control plane is unnecessary. His example uses Kestra, so it is partly a vendor-adjacent view.

Sources: Kai Waehner blog · TLDR Dev

Why it matters: A clean ownership checklist for the system around the model.

Microsoft Clarity trims clarity.js by 1,257 gzip bytes (4.5%) with an agent running 50+ measure-and-revert experiments

Named imports saved 444 bytes and Terser tuning 301. Small helper functions made the gzipped output larger. A 2,308-byte saving from newer JavaScript output was rejected because native async functions would break Zone.js-based Angular sites.
