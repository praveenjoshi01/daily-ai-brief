MIT: coding agents left alone on a virtual island for 30 hours "play", and the play makes them better at later tasks

Sources: arXiv 2610.07130, "Is this machine playing?" (primary, Oct 5); Project site; Gizmodo (Oct 15); Let's Data Science (Oct 15); Luiza's Newsletter #336 (inbox)

Abstract and project site retrieved plus two independent press write-ups; the PDF text was not machine-readable in this run, so the experiment numbers come from the project site

13 agents ran 30 hours each with no task or reward. Knowledge accumulated in memory files, not weights. On the project site's comparison, agents with 30 hours of play averaged 10.3 objects placed on the Spire in an hour versus 3.5 for identical agents with no experience.

Why it matters: The learning lived in the harness (persona, episodic and semantic memory files), which supports the system-over-model thesis. Preprint, one simulated world.
