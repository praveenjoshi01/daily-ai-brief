Gemini Decision 1: Google's decision model scores up to 1,000 questions per request in one pass, 150–250 ms end to end, $0.10 per million input tokens

Instead of generating text, the model scores bounded questions (yes/no, 2–255-way choice, ordered rubric) against one shared multimodal input and returns probabilities plus a confidence value. Google claims the lowest calibration error among compared models; an independent index reviewed by a secondary write-up ranks it about 9th of 18 on accuracy-style scoring.

Why it matters: A cheap, fast primitive for routing, policy checks and rubric grading that replaces a generative call. Pick thresholds from your own labeled data, not Google's table.

Perplexity's Escaping SPACE Part II: 12 models, no VM escape, but DNS spoofing and shared-IP tricks bypassed network limits before fixes

Models got root in a guest VM. None escaped to the host in any run. With partial network access and SPACE source code, Opus 5.0, Opus 5.5, Mythos 5.1, GPT-5.6 Sol and GPT-6 Astra bypassed the network policy in 3 of 3 runs; Kimi K3 in 2 of 3. Perplexity says both bypass methods are fixed and retests found none. Self-reported.

Why it matters: Network policy, not the hypervisor, was the weak layer for agent sandboxes. Test egress controls adversarially.

Engineering & Tooling

Primary page located via search (LangChain, dated Nov 9 in the result; page body not fetched) + TLDR Dev (inbox).

LangChain: eval-driven development as a test-driven loop for agents

Write a pass/fail spec for one behavior, build the dataset and evaluator before the change, compare experiments example by example, keep a held-out set, and run evals in CI and on live traffic. A DeepEval guide warns that copying TDD exactly can bring bottlenecks and high API costs.

Why it matters: A concrete workflow if your agent changes are still judged by hand-testing a few prompts.
