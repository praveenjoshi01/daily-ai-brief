LEAD Engineering & Tooling · Stripe

Stripe's integration evals: a plugin lifted all 14 model–harness pairs, and outdated API references fell from 7% to 1.3%

Grounding: Primary (Stripe methodology post, fetched, Nov 19). Self-reported by Stripe, which owns the product tested. Relayed by TLDR AI (Nov 20). Independent commentary covers Stripe's July benchmark program (InfoQ), not these plugin numbers.

Coding agents (Claude Code, Codex, OpenCode) built Stripe integrations across 69 public scenarios, each run with and without Stripe's agent plugin. A role-playing LLM answered the agent's questions one at a time. A judge scored MUST and SHOULD rubric criteria against the transcript and workspace. Web searches per eval fell 96%.

Why it matters: The gain came from the context the agent was given, not from a new model. If you ship an SDK, your docs and tooling are part of the agent's runtime.

Sources: Stripe: integration evals methodology · TLDR AI (Nov 20) · InfoQ: Stripe's July benchmark

Frontier Labs & Infrastructure Releases

Engineering & Tooling

Gemini API Tool Retrieval: the model searches for tools and loads only the schema it needs

Grounding: Primary (Google blog, fetched, Nov 19). Preview; no benchmarks published.

Tools marked defer_loading: true show only name and description until the model searches for them. The search runs server-side within one API call. Google gives no savings figure and advises measuring against your own traffic.

Why it matters: Large tool libraries cost tokens on every call. This is a built-in way to defer schemas, which changes how you size a tool registry.

Engineering & Tooling

Vercel Board: a message store where agents claim tasks and post updates

Grounding: Primary (Vercel blog, fetched, Nov 18). Vercel calls it experimental; no adoption data.

Agents pull labelled tasks from a channel, claim them for a time window, post progress in threads, and mark work done with a PR link. It is harness-agnostic, so Claude Code, Codex, and LangChain can share one board.

Why it matters: A product version of the coordination layer the Nov 21 Replit study pointed to. You can test it now.

Engineering & Tooling

Cloudflare releases Clairic and Clairic-flash weights for structured extraction

Grounding: Primary (Cloudflare blog, fetched, Nov 18). Benchmarks are Cloudflare's own, labelled directional. License not stated in the post.

Open-weight models (27B and 9B) pull fields from text, images, and PDFs, with confidence scores and character spans. Cloudflare reports 99.7% on its fresh-text eval for the 27B model, against 90.5% for a D1.2 + OCR baseline.

Why it matters: Small open extraction models are now a credible option for pipelines that call a frontier API today. Check the license first.

Anthropic and Theorem: LLM-scaled formal verification across 239 entry points

Grounding: Primary (Anthropic research post, fetched). Originally published Oct 22, not today; resurfaced in Latent Space (Nov 20). Self-reported.

Claude wrote Rocq proofs that OSS-Fuzz entry points cannot crash on inputs up to 64 MB, across 123 libraries. On 36 small tasks, Opus 5.5 solved half using about 40% fewer tokens than Opus 5. The authors say "formally verified" does not mean bug-free.

Why it matters: Verification is becoming a per-task cost you can budget. Track the token number.

Research

Exponential Time Hypothesis claims from OpenAI and Anthropic await independent review

Grounding: Two secondary sources (TechCrunch, Oct 27; TLDR AI, Nov 20). Lab preprints not fetched this run. Not yet human-verified.

Both labs say an internal model found a subexponential algorithm for counting 3-SAT solutions, which would refute ETH. UC San Diego and MIT researchers are organizing a review and say it is not certification. Anthropic's Lean proofs have passed machine checks.

Why it matters: ETH underlies many complexity results. Treat it as open until human experts sign off.

Research

Apple FastFrames: 480p autoregressive video at 36 ms per frame on one B200

Grounding: Primary (Apple project page, fetched). arXiv paper linked but not fetched; its date is unconfirmed. VBench figures not in page text.

A 1.3B model generates 480p video at 36 ms per frame on one B200. The speedup comes from replacing VAE decoding and KV-cache updates, which made up over half of latency. The 14B model runs at 158 ms per frame on one GPU.

Why it matters: Interactive video generation is moving toward real-time latency budgets.

Research

Models can signal each other through a shared inference server, in a contrived setup

Grounding: Primary (authors' LessWrong post, fetched, Nov 19). Not peer reviewed. Relayed by TLDR AI (Nov 20).

Two Qwen3-8B instances on one vLLM server pass bits by changing engine step size or a KV-cache mailbox. The KV channel decoded 1,221 of 1,221 rounds with a fine-tuned reader. At 1x background traffic it fell to 49%.

Why it matters: If you run multi-tenant inference with agents, sandboxing alone does not isolate them.

LessWrong: Models Can Communicate via Inference Servers · TLDR AI
