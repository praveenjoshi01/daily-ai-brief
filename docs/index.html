Sentry's Junior: steering an agent with an egress proxy that denies and reacts

— David Cramer, “A Little Determinism” (Oct 29) · Junior README (Sentry) · Vercel Sandbox credential-injection changelog (via search result; page not opened). Every outbound request from the agent's sandbox passes through a man-in-the-middle proxy. The proxy injects credentials, rejects raw shell calls (e.g. a direct PR-creation mutation) with a 403 that tells the agent which tool to use instead, and turns CI/review events into injected user messages (“watches”). Post reports no benchmarks; evidence is qualitative. Junior's repo is tagged non-production, and its docs confirm only the PR-babysitting behaviour, not the proxy internals. Why it matters: Enforcement at the network boundary is a harness pattern you can copy without touching the model or prompts.

Making agents fast: inference is often not the bottleneck

— Martin Alderson (Oct 29). Single-author practitioner post. Argues thinking budgets, tool-call overhead, sandbox suspend/resume and polling loops can dominate task time. Illustrative example: in a 60-second task, a 2x faster inference tier yields only a 1.25x overall speedup. Author says figures are rough, not benchmarks. Why it matters: Profile the whole loop before paying for a faster model tier.

Vercel AI Gateway “virtual models”

— Vercel blog (Oct 28). An app points at an ID such as vmc/coding-agent; the underlying model, fallbacks and zero-data-retention settings can change without a redeploy, reaching apps within minutes. Vercel says 125 new models from 10+ labs arrived on the gateway in 90 days. Vendor announcement; provider-specific options must be re-checked after a swap. Why it matters: Model choice becomes configuration, so evals on a candidate ID become the safety net.

DeepMind Institute essay: “The Economics of Intelligence”

— DeepMind Institute (Oct 29). Imas, Koh and Legg argue competence and coordination are separate thresholds, and that AI is advancing faster on competence. A small quiz study (100 people) found complementary pairs beat random pairs by 32%. Conceptual essay; the formal model is in a separate paper not reviewed. Not Google's official view. Why it matters: Frames why multi-agent coordination, not single-agent skill, may gate impact.
